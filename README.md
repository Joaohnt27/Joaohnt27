### 🚀 Featured Projects

#### 🏆 CopaNexus

A full-stack platform for managing **2026 World Cup sticker collections**, tracking duplicates for exchanges, and recording purchases and sales.

Developed from scratch and operated in production from **April 6 to October 13, 2026**.

| Production results | Total |
| --- | ---: |
| Registered users | **161** |
| Stickers managed across user inventories | **42,819** |
| Stickers marked as collected | **39,767** |
| Duplicate stickers organized for exchanges | **3,052** |

Collected sticker quantities are aggregated across users' collections. Duplicate quantities represent inventory available for potential exchanges.

The backend includes **JWT authentication, password recovery by email, collection progress tracking and a community announcements feed**.

**Stack:** Java · Spring Boot · PostgreSQL · React

📂 **[Public API repository and technical documentation](https://github.com/Joaohnt27/api-copanexus)**

> Production API retired. Backend source code is available for portfolio review and local development.

#### 📺 Electoral Results System — UNAERP × EPTV

A university team project developed to support electoral results coverage during an **EPTV broadcast**.

I worked on the **Java backend**, contributing to:

- Discovering TSE election data URLs and retrieving results.
- Integrating federal and state deputy results.
- Handling HTTP responses and using ETags to reduce redundant data transfers.
- Maintaining the cloud environment and resolving a database storage issue during production operation.
- Adding JUnit regression tests for integration behavior.

The project was developed in **one month and two days**, by a team of **five developers with support from three professors**, with two TSE testing windows of three days each.

**Stack:** Java · Spring Boot · PostgreSQL · React
